# LPG3 (ILP-530) - Linguagem de Programação III (Eletiva 2)

Materiais e exemplos de apoio da disciplina Linguagem de Programação III (ILP-530) - Fatec Rubens Lara.

## Conteúdos
- Revisão de Orientação a Objetos
- Herança e polimorfismo
- Classes abstratas e interfaces
- Associação, agregação e composição
- Java Swing
- Aplicações Web com Java
- JSP e Servlets
- Introdução ao Spring Boot

## Organização

Este repositório reúne exemplos, códigos de referência e materiais utilizados ao longo da disciplina.

Os exercícios e atividades dos alunos são desenvolvidos em repositórios próprios, individuais ou em grupo, conforme orientação em aula.

## Observação

Nem todos os exercícios trabalhados em aula terão soluções disponibilizadas neste repositório.
